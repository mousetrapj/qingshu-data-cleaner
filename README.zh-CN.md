# 澄数 · Qingshu

[English](README.md) · **简体中文**

在浏览器内运行的表格数据清洗工作台。导入表格、设置明确规则、核对修改与待确认问题，再导出带处理记录的结果。

澄数适用于通用表格、客户资料、教育报名与学员名册、商品目录。界面和常见需求指令支持简体中文与英文，无需应用后端、账户或文件上传服务。

## 本地运行

需要 Node.js 20 或更新版本及 npm。CI 配置覆盖 Node.js 20 和 22。克隆仓库，进入目录后启动应用：

```sh
git clone https://github.com/mousetrapj/qingshu-data-cleaner.git
cd qingshu-data-cleaner
npm run dev
```

打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。无需执行 `npm install`，也不需要构建、API 密钥或运行时 CDN；浏览器依赖已包含在 `dist/vendor/` 中。

开发服务器**仅提供 `dist/` 目录**，默认监听 `127.0.0.1`，不会自动打开浏览器。可以通过 `PORT` 环境变量更换端口，通过 `HOST` 调整监听地址。

部署时，将 `dist/` 的内容放到支持 JavaScript 模块正确 MIME 类型的静态托管服务即可。保留 `vendor/` 和对应许可说明；单独分发应用而不包含完整仓库时，也应附带 `LICENSE` 和 `THIRD_PARTY_NOTICES.md`。请通过 HTTP 或 HTTPS 访问，不要用 `file://` 直接打开 `index.html`。

## 使用流程

1. **导入表格。** 支持 CSV、TSV、TXT 表格和 XLSX，也可以粘贴含表头的表格。多工作表文件可以选择要处理的工作表。
2. **选择预设。** 核对字段类型、必填项、导出列名与去重依据。预设只是可调整的初始配置。
3. **录入需求。** 可以逐条描述清洗要求，生成草案后核对并应用。未识别的要求会保留为待确认，不会自动执行。
4. **运行与检查。** 查看原始值、处理后值、修改原因和待确认问题。变更规则或需求后，旧结果会标记过期。
5. **导出结果。** 下载清洗数据、问题清单和报告。待确认记录仍会保留在输出中，除非符合明确启用的移除规则。

语言选择器可以切换简体中文和英文。切换会改变界面和生成的说明，不会翻译导入的表格值，也不会擅自重命名原始字段。

### 支持的清洗规则

| 范围 | 行为 |
| --- | --- |
| 文本 | 去除首尾空白；可选将全角 ASCII 字符转为半角。保留内容内部的空格。 |
| 编号 | 学号、商品编码等按文本保留，包括源数据中已有的前导零。 |
| 必填项 | 报告缺失，不编造补充值。 |
| 手机号 | 处理**中国大陆手机号**的基础格式，包括空格、短横线和支持的区号前缀。 |
| 邮箱 | 检查基础结构，仅将域名转为小写，保留 `@` 前的大小写。 |
| 日期 | 将有效且无歧义的年在前日期规范为 `YYYY-MM-DD`，保留支持的时间和时区后缀。 |
| 数值 | 移除合法千分位并规范明确的十进制格式，不做浮点舍入或猜测币种。 |
| 重复记录 | 标记重复，或移除清洗后完全相同的重复行；同键内容冲突的整组记录保留。 |
| 全空行 | 表头之后的全空记录可保留或移除，移除操作进入处理记录。 |

教育报名表建议按**学号 + 课程**建立联合去重依据，避免把同一学员的不同课程报名当成同一条记录。任一已选键为空的记录不参与重复移除。未选键而启用完全相同记录移除时，按清洗后的整行内容匹配。

### 需求示例

针对包含“学号、姓名、课程、手机号、邮箱、报名日期”的表格，可以每行写一条：

```text
去除首尾空白
学号保留前导零
姓名和学号必填
按学号+课程检查重复
仅移除完全相同的重复行
同键冲突全部保留
报名日期统一为 YYYY-MM-DD
邮箱域名转小写
```

也支持英文指令，例如 `Preserve leading zeros in Student ID`、`Check duplicates by Student ID + Course`。字段名要与当前表格相符；界面切换语言不会自动翻译表头。

需求识别使用确定性规则解析器，并非通用 AI 代理。应用前请检查草案。“补齐所有手机号”“合并看起来相似的公司”等要求需要进一步定义业务规则，不会被默认为已经完成。手动覆盖草案或修改需求文字后，报告会记录相应状态。

## 导出与追溯

| 导出项 | 内容 |
| --- | --- |
| 完整 Excel 结果 | 清洗数据、待确认问题、修改明细、重复检查、移除记录、字段规则与处理报告；较长的审计表会拆为多个工作表。 |
| 异常与移除清单 | 单独导出问题、重复和移除记录。 |
| 安全 CSV | 清洗后的数据；对可能被表格软件当作公式的文本添加保护前缀。 |
| JSON 报告 | 统计、规则配置、需求状态和导入说明，不包含整张输入表格。 |

**XLSX 输出全部使用文本单元格**，包括金额和日期，以保留精确值并避免执行公式。如果目标系统需要数值或日期类型，请按其要求另行转换。安全 CSV 可能为风险文本增加单引号前缀，且表格软件打开 CSV 时仍可能推断数值类型。需要保留前导零或长编号时，请优先选择 XLSX。

每次清洗都从导入值重新计算。报告绑定本次运行时的配置，并保留源文件行号。工具不会修改原文件。

## 限制与边界

- 输入限制：单文件 **10 MB**、每工作表 **50,000 条数据记录**、**100 列**。第一条非空行为表头，超限输入会被拒绝，不会直接截断。
- 支持现代 `.xlsx`；旧版 `.xls` 需要先另存为 XLSX 或 CSV。
- CSV 支持自动识别编码与分隔符，也可以明确指定。来源编码不确定时，请核对预览。
- 手机号只检查中国大陆移动号码格式，不验证号码是否属于某人、是否可接通，也不提供国际号码通用校验。
- `02/03/2026` 等月日顺序不明确的日期、无效日期、错误金额和其他不确定值会保留并提示。
- 不编造缺失信息，无法恢复源文件已经丢失的前导零或长数字位数。
- 不执行 XLSX 公式；可能读取已有缓存结果。缓存缺失或其他导入限制会提示人工核对。
- 不自动合并冲突，不联网验证身份、地址或联系人真实性。
- 自动化检查覆盖代码和数据处理行为，不能替代浏览器交互检查与具体业务规则验证。

## 数据与浏览器存储

文件内容在当前浏览器中处理，应用不会上传表格。清洗流程不包含分析服务或远程 AI 请求。刷新或关闭页面后，需要重新导入源文件。

“我的预设”只保存配置，不保存表格记录。预设和界面语言保存在当前浏览器的本地存储中，不会跨浏览器同步。离开页面前，请下载需要保留的结果。

## 开发与验证

```sh
npm run check
npm test
```

`check` 检查 JavaScript 语法及本地静态资源引用；`test` 使用 Node 内置测试运行器执行仓库测试。测试加载与浏览器相同的已入库 vendor 文件，无需额外安装，也不依赖私有运行时路径。CI 在 Node 20 和 22 上分别执行这两个命令。

| 路径 | 用途 |
| --- | --- |
| `dist/index.html`、`dist/styles.css`、`dist/app.js` | 工作台界面与交互 |
| `dist/engine.js` | 清洗规则与需求解析 |
| `dist/io.js` | CSV/TSV/XLSX 读写 |
| `dist/report.js` | 运行快照、需求状态与审计表 |
| `dist/presets.js` | 可编辑预设与虚构示例 |
| `dist/i18n.js` | 明确的中英文消息处理 |
| `dist/vendor/` | 已入库浏览器依赖与许可副本 |
| `scripts/` | 不依赖第三方安装的开发、检查和测试命令 |
| `tests/` | 数据完整性与集成测试 |

仓库没有额外生成的构建目录，直接修改 `dist/` 下的应用文件。开发流程、本地化规范和规则设计说明见 [CONTRIBUTING.zh-CN.md](CONTRIBUTING.zh-CN.md)。
